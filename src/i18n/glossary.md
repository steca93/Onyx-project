# Glossary — sr / en / de

Fixed terms for all translations: the catalog overlay (`src/i18n/catalog/*.json`), UI messages (`messages/*.json`), and SEO copy (`reports/seo-suggestions.csv`). When a term is here, use exactly this form.

## Never translate
| Term | Note |
|---|---|
| **ONYX EVOLUTION** | Brand, always uppercase in titles and the logo. "ONYX Evolution" is allowed inside running product names, where WooCommerce already writes it that way. |
| **ONYX Warranty** | Name of the warranty program. |
| **PPF** | Paint Protection Film. Keep the abbreviation in every language. |
| Model names | Multi Wipe, Waffle Wipe, Glass Wipe, Polishing Wipe, Fish Scale, Rapid Dryer, Ultra Dryer, Hex, Hot Wheel, EVO Clear |
| Pad cut grades | **Heavy Cut, Medium Cut, Polishing, Finishing**: English trade terms, kept in de and sr. |
| Units | 130 mm, 125 mm, 1000 GSM, 1,52 × 15 m, µm. The number format follows the language (sr/de: `1,52`; en: `1.52`). |
| Currency | **RSD** in every language. There is no conversion. |

## Style
- **sr:** Latin script, never Cyrillic. Use the polite plural in calls to action ("Poručite", "Pogledajte"); the UI keeps its existing informal tone ("tvoja korpa"). Write "sunđer", not "sundjer".
- **en:** US spelling (color, center).
- **de:** formal "Sie". Compounds with a hyphen after an abbreviation: "PPF-Folie".
